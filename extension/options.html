Opções do Vortex Mídia

Configuração de captura e integração com o editor

Para onde a mídia capturada é enviada. Em desenvolvimento: http://localhost:5173

A captura direta funciona sem servidor em sites comuns (imagens, MP4 abertos, MP3). Para YouTube, TikTok, Instagram, Facebook e X é necessário um motor que resolva os links — nenhum deles expõe o arquivo na página por causa de DRM/segmentação. Deixe vazio para operar só no modo direto.

Como a extensão funciona

1. Captura direta (sem servidor). Lê os elementos da página: tags <video>, <audio>, <img>, metatags OpenGraph, JSON-LD e backgrounds grandes. Funciona em portais de notícia, blogs, sites institucionais, bancos de imagem e a maioria dos vídeos HTML5.

2. Envio ao editor. Cada item capturado pode ir para a biblioteca do Vortex Editor com um clique (canal direto externally_connectable).

3. Motor (opcional). Só é necessário para plataformas fechadas. É um servidor seu ou contratado.
